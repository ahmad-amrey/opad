## Downloads

| Platform | File | How to start |
|---|---|---|
| Windows 10/11 (64-bit) | `OPAD-@VERSION@-windows-x64-setup.exe` | Run the installer: OPAD goes to your Start menu (no administrator needed). Updating keeps your settings. |
| Windows, no install | `OPAD-@VERSION@-windows-x64.exe` | One file: run it from any folder. It keeps its settings in an `opad-data` folder beside itself. |
| macOS (Apple Silicon) | `OPAD-@VERSION@-macos.dmg` | Open the dmg and drag OPAD to Applications. |
| Linux (x86-64) | `OPAD-@VERSION@-linux-x86_64.AppImage` | Make it executable (`chmod +x`), then run it. |

`opad-cli-@VERSION@-windows-x64.exe` is the command-line tool. `SHA256SUMS.txt` holds the files' checksums; the
`THIRD-PARTY-NOTICES-*.txt` files list the libraries each package carries and their licences.

**First start of an unsigned build.** Windows may show "Windows protected your PC": choose *More info*, then *Run
anyway*. macOS may say the app cannot be checked: right-click OPAD in Applications, choose *Open*, then *Open* again.
